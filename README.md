# Mama Bobba

## Website
Visit us at: [mamaboba.netlify.app](https://mamaboba.netlify.app)

## Description
    This is a bubble tea brand website showcasing popping boba products with an engaging hero section, product catalog organized by flavors (strawberry, dragon fruit, mango, melon, peach), and interactive hover effects. The site features smooth animations, gradient backgrounds, and includes company information, contact details, store locator, FAQ, and social media links in the footer. I tried to replicate the original website https://bobbadrink.com/. The original website was made with react js and TypeScript CSS, but my project used only HTML, CSS and JS. The images used on the website are from the original website.

## Features
- Product showcase with multiple flavor varieties
- Interactive hover effects on product images
- Store locator
- FAQ section
- Contact information
- Social media links
